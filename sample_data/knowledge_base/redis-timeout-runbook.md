# Runbook: Redis 连接池耗尽导致接口 timeout

## 现象
高峰期在线接口（如 chat / 审批 Agent）出现偶发 timeout，错误率随 QPS 上升。

## 常见根因
- 连接池 max_connections 过小，突发流量下连接排队。
- 慢查询或大 key 阻塞连接，连接无法及时归还。
- 下游模型推理排队，上游持有连接等待，放大占用。

## 处置
1. 临时：调大连接池、设置合理 socket_timeout，隔离慢调用。
2. 根治：接口侧加超时与熔断；对模型调用做排队与限流；加连接池使用率监控与告警。

## 相关指标
`redis_pool_in_use`、接口 P99、模型队列深度。
